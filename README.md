# 📊 Task 4: Dashboard Design

## 📌 Project Overview

This project is part of the **Data Analyst Internship – Task 4**. The objective is to design an **interactive dashboard for business stakeholders** using a Sales/Financial dataset.

## 🎓 Interview Questions

### 1. What are the key elements of a dashboard?

KPIs, charts, tables, filters, slicers, titles, and interactive elements are the key components of a dashboard.

### 2. What is a KPI?

KPI stands for **Key Performance Indicator**. It is a measurable value used to evaluate business performance.

### 3. What are slicers in Power BI?

Slicers are interactive filters that allow users to filter dashboard data based on selected values.

### 4. What is the difference between Power BI and Tableau?

Both are business intelligence and visualization tools. Power BI is developed by Microsoft, while Tableau is developed by Salesforce.

### 5. How do you make a dashboard interactive?

Interactivity can be created using slicers, filters, drill-downs, buttons, navigation, and interactive charts.

### 6. How do you deal with large datasets in dashboards?

Large datasets can be handled using data modeling, filtering, aggregation, optimized queries, and appropriate storage modes.

### 7. What chart types are used for trend analysis?

**Line charts** are commonly used to show trends over time.
